## 🚀 Products

### 🧪 MATE — Beta/UX testing platform on the Toss mini-app ecosystem
<sub>`2026.04 – Present` · Product Manager</sub>

**Before launch**
- **Researched** app-tech users and makers with beta/UT experience in two rounds, and **defined** 3 maker pain points: finding users, getting actionable feedback, and managing rewards
- **Designed** the core flow — test registration with 8 UX test templates, reward payment, automatic payouts, and PDF/CSV result reports
- **Redesigned** 3 flows (A/B choice, question editing, test preview) through hypothesis → UT → fix
- **Built** the business model, TAM/SAM/SOM sizing, RFM user segments, and 3-month post-launch KPIs

**After launch** (within 1 month of launch)
- **Hit** the 3-month cumulative user KPI within **3 weeks** of launch
- **Discovered** that new test releases drive retention — the launch-day cohort revisited **~6×** more on a release day than on an average day
- **Grew** the returning-user share of WAU by **+30.4%p** in three weeks, with WAU up **+60.9%** week-over-week in the week a new test was released
- **Designed** follow-up experiments on release cadence, Discover-tab layout, and per-test growth funnels

<details>
<summary><b>🚢 Titanic Survival Prediction</b> — ML course assignment</summary>
<br/>

- **Cleaned** the data — filled Age with KNN imputation, Embarked with the first-class mode, and grouped Cabin by deck with an "Unknown" class
- **Capped** Fare outliers with the IQR rule, then **encoded** categorical features and **scaled** numeric ones
- **Tuned** Logistic Regression (penalty, regularization strength, iterations) with GridSearchCV, raising test accuracy **+6.2%p** over the default regularized model
- **Interpreted** coefficients — sex had the strongest effect on survival, followed by class and fare
- **Compared** the model with a Decision Tree and **visualized** its decision boundary on age and fare
